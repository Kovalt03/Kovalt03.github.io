## 수정 방법

`index.html` 의 `<nav class="links">` 안에 있는 `<a class="item">` 블록을 복사해
`href`, `label`, `desc` 만 바꾸면 링크가 추가됩니다. 다크 모드는 CSS 변수로 자동 적용됩니다.
